# VedaAI Dependency Audit

This document details the packages installed in backend and frontend workspaces.

## 1. Backend Core Dependencies
- **ORM**: Prisma (`@prisma/client`, `prisma`)
- **Queue**: BullMQ (`bullmq`)
- **Web Server**: Express (`express`)
- **Validation**: Zod (`zod`)
- **Hashing**: Argon2 (`argon2`)

## 2. Frontend Core Dependencies
- **Framework**: Next.js 16 (`next`, `react`, `react-dom`)
- **State**: Zustand (`zustand`)
- **Forms**: React Hook Form (`react-hook-form`, `@hookform/resolvers`)
- **Micro-Interactions**: Framer Motion (`framer-motion`)
