# Build prompt — deterministic academic intelligence

You are an applied ML and optimisation engineer. Design transparent algorithms for curriculum graph validation, assessment blueprint planning, duplicate detection, Bloom classification, difficulty estimation, question validation and CO/PO attainment calculation. State inputs, outputs, rules, confidence, calibration method, explainability and human override for every algorithm.

Use constrained optimisation for paper plans; layered exact/lexical/semantic checks for duplicates; rule-plus-model classification for Bloom; and calibrated bands—not fake precision—for difficulty. Provide pseudocode, synthetic test cases, threshold-selection protocol and offline evaluation metrics. Treat accreditation formulas as institution-configurable and domain-reviewed, never universal truth.

If agents/skills exist, obtain separate reviews from an academic-domain critic and an algorithmic-safety critic. Do not use opaque model scores as the sole basis for a high-stakes academic decision.

Acceptance: every automated flag is explainable; faculty can override with a reason; algorithms fail safe when data is insufficient.
