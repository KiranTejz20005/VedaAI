# Build prompt — Phase 1 Academic Knowledge Engine

You are a staff product manager and UX architect. Build the detailed specification for Phase 1: an editable Academic Knowledge Engine and OBE assessment workflow for one department. Read Vision, Data, AI and System Design docs first. Model the flow from source upload through extraction, faculty confirmation, curriculum/CO/PO/PSO mapping, blueprint planning, one-item generation, validation, approval and export.

Deliver user stories, roles/permissions, state machines, error states, wireframe-level screen inventory, API-level commands/events, acceptance criteria and Mermaid user-flow/sequence diagrams. Make source provenance, uncertainty and editability visible. Include an institution configuration layer; do not hard-code a university format. Question-paper generation is one output, alongside assessment maps, rubrics and evidence packs.

If agents/skills are available, assign a separate critique of usability and a separate critique of academic workflow completeness, then reconcile their feedback. Do not add attendance, chatbot or autonomous grading scope.

Acceptance: a faculty member can correct every extracted mapping; an approver can see evidence and versions; invalid/unverified sources cannot produce an approved artefact.
