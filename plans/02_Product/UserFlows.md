# User flows
1. Admin creates term and assigns roles.
2. Faculty uploads/reviews curriculum sources and outcomes.
3. Faculty sets a blueprint; system shows unmet constraints.
4. VidyaAI retrieves sources and drafts candidates.
5. Reviewer edits, accepts/rejects and records rationale.
6. Validator blocks invalid papers; approver signs off.
7. System exports the approved version and retains the audit trail.
