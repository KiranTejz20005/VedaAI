# Build prompt — customer and market validation

Act as a rigorous B2B edtech researcher. Use current primary sources and cite every time-sensitive claim. Focus on Indian engineering colleges, beginning with one target university ecosystem only after interviews. Do not manufacture TAM, competitor capabilities, pricing or willingness-to-pay figures.

Produce: interview scripts for principal, HOD, COE, IQAC/OBE lead, faculty and IT; a workflow pain map; a competitor/alternative matrix; bottoms-up TAM/SAM/SOM model with editable assumptions; and a pilot qualification scorecard. Test the core hypothesis: institutions pay for faster, traceable OBE/accreditation and assessment workflows, not merely question generation.

Use available web/research skills or agents only for bounded source collection; synthesise findings into Markdown in this folder. Keep research evidence separate from hypotheses. Include decision criteria for rejecting the segment.

Acceptance: 20-interview plan, 3-pilot qualification gates, named economic buyer, quantified baseline metrics and a clear “do not build yet” list.
